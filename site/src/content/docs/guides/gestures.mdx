Every touch gesture on home, at a glance:

<GestureMap>

1. **Swipe down on the header**: the notification shade (`gesture.swipe-down`).
2. **Double-tap empty space**: lock the screen (`gesture.double-tap`). One tap brings up the keyboard.
3. **Pinch the log**: bigger or smaller text.
4. **Swipe sideways** on the header, empty space or the prompt: the [widgets page](/guides/widgets/).
5. **Long-press a line**: its actions. A tap does its main action.
6. **Swipe a line**: right copies it, left deletes it (with Undo for a few seconds).
7. **Tap the `$`**: quick actions.
8. **Swipe up on the prompt**: nothing, unless you set `gesture.swipe-up`.
9. **Slide along the edge**: the [app selector](/getting-started/basics/#app-selector), when it's on.

</GestureMap>

Three gestures are configurable, in **Settings → Gestures** or with `config set`:

| Gesture | Key | Default |
| --- | --- | --- |
| Double-tap empty log space | `gesture.double-tap` | `lock` (`none` in the Play build, which has no screen lock) |
| Swipe down on the header | `gesture.swipe-down` | `shade` |
| Swipe up on the prompt | `gesture.swipe-up` | `none` (off: it fires by accident easily) |

Each value is one of:

- `lock`: lock the screen,
- `shade`: pull down the notification shade,
- `quick`: open the quick actions (as tapping `$` on the prompt does),
- `none`: do nothing,
- **any command**, run as if you typed it.

```sh
config set gesture.swipe-up apps -l   # swipe up on the prompt for the app list
config set gesture.double-tap feed read
config set gesture.swipe-down none
```

`lock` and `shade` are also commands you can type, alias or use from a script command.

## Locking needs an accessibility service

Android only lets an app lock the screen through an accessibility service. Kolahal ships a tiny one,
**Kolahal screen lock**, that does nothing else. It is declared with `canRetrieveWindowContent="false"`
and scoped to a package that doesn't exist, so it receives no accessibility events and can't read
the screen. All it does is call the system "lock screen" action.

Enable it with `accessibility` or **setup → Double-tap to lock**. Until then, `lock` prints a
tappable line that takes you to the setting.

## Other touch gestures

These are fixed:

- **Pinch** the log to change the text size. When you let go, a toast says the new size.
- **Tap** empty space to show the keyboard.
- **Drag sideways** across the key bar to move the cursor.

## A flash of wallpaper on the way home

With gesture navigation, going home from an app passes through your phone's own launcher, which
shows the wallpaper for an instant: Android keeps those gestures for it, whichever home app you use.
Three-button navigation doesn't have the flash. To keep the gestures, `wallpaper match` sets the home
screen's wallpaper to the theme's colour, so nothing stands out, and changes it with the theme, in
dark mode too. Set another wallpaper and Kolahal leaves it alone from then on; `wallpaper` says which
it is. It asks first, as the old wallpaper can't be brought back; the lock screen keeps its own.
`log.wallpaper` and `widgets.wallpaper` then show only that colour.
