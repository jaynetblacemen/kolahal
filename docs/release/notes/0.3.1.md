> **Before you install:** this version is signed with Kolahal's new release key, so it can't install over 0.3.0 or earlier. Move once, keeping everything:
>
> 1. Settings → Backup → Export everything, and keep the file outside the app.
> 2. Uninstall Kolahal.
> 3. Install this version and make it the home app again.
> 4. Settings → Backup → Import a backup.
> 5. Run `setup` to grant the permissions again, and add your widgets again (`widget add`). A backup lists them but can't carry them over. The same goes for the folder picked with `script dir`.
>
> Later versions install over this one as usual.

Kolahal 0.3.1, package `com.mtwabpin.kolahal`, Android 9 or newer: **kolahal-0.3.1.apk**.

**No lite APK from this version.** If you had it, take this APK (the move above). Kolahal is coming to Google Play instead, as the same app without the screen lock, notifications in the log and calls in the log, which Play's policy rules out.

Play Protect blocks sideloaded apps that have an accessibility service or notification access (in India and some other countries). To install where it does: Play Store → profile → Play Protect → ⚙ → turn off "Scan apps with Play Protect", install, then turn it back on.

## What's new

- **Make your own themes**: Settings → Look & feel → Your themes. Start from any theme and change each of its 12 colours with a picker (hue, saturation and lightness sliders, a hex field and swatches), while a small home screen shows the result. Saved themes appear in the theme strip and in `theme`, and backups carry them.
- **Settings always use your theme's colours.** `theme.settings-colors` is gone.
- **Turn the header off completely**: Settings → Home screen → Header → Show the header (`header.show`). The log then takes the whole screen; the `settings` command still opens Settings.
- **App icons in the suggestions** are on by default (`suggestions.icons`). If you turned them off yourself, they stay off.
- **A new app icon**: the log, two lines with their coloured bars over the prompt and its cursor.
- **About in Settings**: Guide (opens the website), Crash reports (each report shows what it holds; email it to the developer or delete it), Email the developer (a draft with the version, Android version and phone model), and Version (tap to copy).
- **Settings shows only what applies.** A setting that depends on another stays hidden until that one allows it, for example the key bar's rows while the key bar is off. `config` still reaches all of them.

## Removed

- **Home widgets.** Widgets live on the widgets page only. `widgets.home`, `widgets.height` and `widget add home` are gone, and `config` says where their job went.
- **The lite APK** (above).

**kolahal-0.3.1-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
