Kolahal 0.4.3, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.2 and keeps your data and settings.

- **kolahal-0.4.3.apk**: the full build.
- **kolahal-0.4.3-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no notifications in the log, no media controls and no calls in the log. Play Protect blocks sideloaded apps that have an accessibility service or notification access (in India and some other countries); this one has neither, so take it if the full build won't install. Both APKs use the same package and key, so either installs over the other.

## What's new

- **`fetch`** (or `neofetch`, `fastfetch`): this phone and Kolahal at a glance, as fastfetch shows a computer: Kolahal's icon beside the Android version, device, uptime, Kolahal's version, apps, scripts, theme, display, CPU, memory, storage, battery and more, then the theme's colours. It fits the screen: on a narrow one the icon goes above.
- **`date <place>`**: the time somewhere else, and how far ahead or behind it is: `date tokyo`, `date new york london`, `date Asia/Kolkata`, `date utc`, `date +5:30`. Places complete as you type.
- **`cal`**: the month as a calendar, today in bold, weeks starting on your locale's day: `cal`, `cal dec`, `cal dec 2027`, `cal 2027-12`.
- **Paper, early**: `config set theme.paper 30` puts an old book's page behind home in light versions, more worn the higher the number. It isn't in Settings yet and stays off unless you set it.

## Changed

- **Settings, Scripts and Feeds**: the tabs at the top of Settings put Scripts before Feeds.
- **The log's groups sit closer**: the gap above each one (`log.spacing`) is 5 dp unless you set it, down from 10.
- **The app selector** is off unless you turn it on (Settings → Typing → **Show the app selector**). It can sit on the right edge or the left (**Edge**), at the bottom, middle or top of it (**Where on the edge**), so it stays away from where you swipe back. Its list opens on the other side of the screen, and the app you're at sits level with your thumb, with its letter, so your eyes stay at your thumb's height. Picking needs a clearer slide off the edge, and holding for an app's actions most of a second, so a resting thumb doesn't open them.
- **A denser log**: lines are 22 dp unless you set them (down from 25), all the same height: lines you can tap are no longer taller unless you turn on Settings → Log → **Taller tappable lines** (`log.taller-taps`). **Line height** now goes as low as the text allows: below a line of text, the room above and below it goes. It follows the phone's text size now, so a larger system text size doesn't squeeze the lines.
- **Library scripts you haven't edited update with Kolahal**: an update's newer copies replace them by themselves, timers and switches kept, and the log says which. Anything new an updated script asks for (`@uses`, `@on`) stays off until you allow it, and the log says so. Edited ones stay yours, marked "edited", with **Reset to the library's** in the script manager.
- **Suggestions**: a synonym (`ls`, `cls`, `launch`, `screentime`) completes like the command it stands for; a whole command's own options come before longer commands (`feed` offers `feed add` before `feeds`); commands you used lately come first; names, keys and options match in any case (`theme Am`); `script install` and `script get` offer the library's and the shared scripts, `unhide` and `unpin` only what they can undo, `notifs unmute` only muted apps, `script on` and `off` only what isn't; `feed notify`, `feed every`, `script every` and `script notify` offer their values, `config set gesture.…` its actions, `remind` its `exact`; an earlier line a live row stands for (`open maps` beside Maps) isn't offered twice, nor lines that named an item by a number that has since moved; personal apps carry no `[P]`; the Play build offers nothing for what it can't do; `suggestions.max` is the real limit. With icons on, feeds, scripts, contacts, todos, notes, reminders, settings and `log only` rows show an icon of their kind, and a command script's `@desc` shows beside it.
- **The script manager's details switch things**: each thing a script may do (internet, its header line, notifications, what it declares, its events) is a pill, ✓ when on and ✕ when off; a tap switches it.
- **A lighter log**: under `log only …`, a new line is checked as it comes instead of the whole log being searched again for every line; `/word` searches let the database rule most lines out first; a command's output is written in one go instead of a line at a time; scrolling back reads only the older page; a swiped line, a launch line moved down, and a trim of lines older than the screen no longer make home read the page again; and the log is trimmed to `log.keep-lines` as it grows, not only after script runs and restarts.
- **Lines read like English**: the app's own lines, notices, hints, usage errors and `help`'s section headers start with a capital letter, and Android's names are written its way (Do Not Disturb, Wi‑Fi, Bluetooth, Play Store).
- **Library scripts line up and read alike**: countdown, crypto, exchange and forecast print their values in columns; their descriptions, titles and lines start with a capital letter ("Network error: …", "Usage: …"); crypto's change reads `▲ 1.2%`, reddit counts points, and hn ends with `+3 more` as the feeds do. Copies you haven't edited update by themselves.
- **Scripts can line up columns**: `mono = "1"` in a line's context keeps it in the terminal font even with `font.sans all`, so values padded with spaces stay in their columns.
- **The script manager says why a run failed** as the editor does: "Line 7: …", "Stopped: internet switched off", "Stopped after 60s".
- **An app's long-press menu** lists its shortcuts as "Maps › Navigate home", lined up with the other actions; Lock screen in Quick actions has the lock icon.

## Fixed

- **Scripts that run on unlock (`@on unlock`) run again**, and the unlock count no longer needs Usage Access to count: the unlock broadcast wasn't reaching Kolahal.
- **Lua scripts**: `true`, `false` and tables passed to `log`, `status`, `notify`, `store.set` and the `fmt` functions read as text, as `tostring` shows them, instead of `nil` (`store.set("done", true)` deleted the key, so such a script notified on every run). `logs({})` logs nothing instead of failing. A JavaScript `NaN` logs as `null`, and huge whole numbers aren't clamped.
- **`http.request`**: a `Content-Type` header you pass is sent (it was replaced by `text/plain`), and a table or object body is sent as JSON.
- **Scripts**: an `@on` event with a lot of text (a long notification) still starts its script, the text cut to fit; a script whose store is full makes room by dropping its cached web responses first; and a line's "Copy text" that is its own link stays, even when Kolahal tidied the link (a `/` added).
- **Script folders**: an export now records what it wrote, so a later export removes the files of scripts you deleted since, and `script import` doesn't bring them back. Importing a file over a script you have works even if an app shares its name.
- **The library's automatic updates** retry a copy that failed to update, instead of leaving it behind until the library changes again.
- **The log**: a line that arrived on its own (an app you tapped, a call) no longer offers "Run '…' again" for an unrelated earlier command. Lines seen before `fresh` don't come back as unread. Under `log only`, older lines load, and tapping a search result the filter would hide ends the filter. A hard fling to the newest line no longer leaves new lines arriving unseen below the screen. A line swiped away goes at once, even while a slow command runs. Searching for a word with quotes finds it in a line's body. "Yesterday" moves on at midnight. An `apps` grid drops a chip you uninstall or hide.
- **The header clock** keeps time after the phone sleeps, and follows a change of time zone.
- **A script with internet switched off** can't send anything off the phone through a picture or a link on its lines any more: its lines get neither. A link or a picture that carries a secret goes only to the sites the `@secret` line names, as a request does; and a secret is never sent over plain http, from a request, a redirect or a link.
- **`launcher.run`** refuses what stays with you, like the other sensitive commands: an app's shortcut (`open phone:mom` could place a call), resuming a paused profile (`--resume`), asking for a permission (`--allow`), opening app settings (`--settings`) or app info, and the Wi‑Fi, Bluetooth, NFC and internet panels. Typing `wi` on the way to something else no longer opens the Wi‑Fi panel either.
- **A restored backup's lines** can't run a command or open a contact from outside the contacts app on a tap.
- **Backups and transfers leave out the scripts' work queue**: while an `@on notification` script waits to run, the queue holds that notification's text.
- **A conversation's next message** is logged (and reaches `@on notification` scripts). Chat apps deliver it as a silent update of the same notification, which was treated like a timer's tick and skipped; now a message notification whose text changed counts, one line per 30 seconds as before.
- **Typing**: `alias hf = help | grep feed` keeps its pipe; `log only` suggests the kinds and sources; `todo clear out the garage` adds a todo (`todo clear` alone clears finished ones); `notes add` with nothing says so; `open` finds an app whose name has a colon; `feed rm`, `every`, `notify`, `on` and `off` refuse an id no feed has; an alias can't take a built-in's name in another case; `config set keybar.row2 ""` empties it; commands that leave the launcher (`system`, `battery`, …) never run on a prefix.
- **The app selector**: works with a short list of apps, keeps its place when the strip is moved, doesn't flicker between browsing and picking at the boundary, and grows its rows with the text size. A tap on empty log space brings the keyboard up at once when no double-tap gesture is set.
- **Settings and pages**: the feed sheet's "Refresh every" takes effect at once; the theme builder's name field doesn't carry over from the last visit (which could rename a theme); Settings reopens on its main page; theme cards follow Always dark at once; the editor's Run keeps your edits if the save fails; two shared scripts with one name can't crash Get more scripts.
- **Feeds** fetched in a run the system cuts short are still reported.

**kolahal-0.4.3-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
