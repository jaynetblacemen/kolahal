Kolahal 0.4.5, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.4 and keeps your data and settings.

- **kolahal-0.4.5.apk**: the full build.
- **kolahal-0.4.5-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no notifications in the log, no media controls and no calls in the log. Play Protect blocks sideloaded apps that have an accessibility service or notification access (in India and some other countries); this one has neither, so take it if the full build won't install. Both APKs use the same package and key, so either installs over the other.

## What's new

- **The phone's wallpaper behind home**: the log and the widgets page can each show the wallpaper you set in Android, as much as you like: **Wallpaper showing** under **Settings → Log** (`log.wallpaper`) and **Settings → Home screen** (`widgets.wallpaper`), from 0 (none, as before) to 100 (all of it, with none of the theme's colour over it).

**kolahal-0.4.5-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
