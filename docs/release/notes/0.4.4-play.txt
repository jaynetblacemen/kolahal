Thanks for testing Kolahal, a home screen you type into. Type part of an app's name and it opens; type help to see commands such as remind, cal and fetch. To start, make Kolahal your home app (type home), then type tour for a short walk-through and setup for the optional permissions. Scripts and themes are in Settings. Nothing you type is sent to us. If Kolahal crashes, type crashes share to send the report; anything else that looks wrong, tell us what you saw.
