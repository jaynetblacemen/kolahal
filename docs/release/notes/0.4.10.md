Kolahal 0.4.10, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.9 and keeps your data and settings.

- **kolahal-0.4.10.apk**: the full build.
- **kolahal-0.4.10-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap) and no calls in the log, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## What's new

- **A shorter key bar**: one row by default, with only what the keyboard's letters page leaves out: `/`, `|`, `=` and the four arrows. Esc, Tab, Home, End, backspace, Enter, `-` and `.` left the default, as the keyboard or the ✕ beside the prompt has most of them, and you can still add any of them with `keybar.row1` and `keybar.row2`. A row you changed stays as you set it. To bring the old bar back: `config set keybar.row1 ESC,/,-,HOME,UP,END,BKSP` and `config set keybar.row2 TAB,|,.,LEFT,DOWN,RIGHT,ENTER`.
- **A selector for timers**: **Runs every** on a script and **Refresh every** on a feed are now one button that says the time and opens a menu, in place of a row of seven or eight. A time set from the terminal, such as `script every weather 2h`, shows on it too.
- **A tidier crash report**: Settings → About → Crash reports → a report shows **Email to Us**, with Share and Delete as icons beside it.
- **Kolahal no longer reaches your local network**: the local network permission, the `local-network` command and `@uses lan` are gone, on every Android version. Scripts, code at the prompt and feeds reach public sites only, so a script that had `@uses lan`, a feed on a home server or a VPN address like Tailscale's 100.x now fails with "points to this phone or the local network: not allowed here". An `@uses lan` line is ignored, and the editor flags it.

## Fixed

- **Scripts with a VPN on**: a VPN that covers the internet in parts, as those that leave your local network alone do, made every public site count as local. Scripts without `@uses lan` failed with "zenquotes.io is this phone or the local network: not allowed here", and pictures in the log didn't load. A VPN that carries the internet doesn't count as your network now, one that only reaches a network of its own still does, and your real networks stay local underneath either. The message also says "points to" now, as a filtering DNS or a Wi-Fi login page can cause it too.
- **Pipes without a space**: `help|grep feed` said "Command not found", and the key bar's `|` adds no space. The spaces around a `|` are optional now, but with no space before it, it stays in a `grep` pattern, code, quotes and text you're saving: `grep head|tail` still finds either word.
- **↓ after editing a recalled line**: press ↑, add a symbol from the key bar and press ↓, and the edit was lost. It stays now, as it does when you type on the keyboard. The same goes for a line filled from a suggestion.
- **The Play build and `lock`**: the suggestions and descriptions for the gesture settings offered `lock`, which that build doesn't have. They don't now.

**kolahal-0.4.10-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
