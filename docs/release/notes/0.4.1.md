Kolahal 0.4.1, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.0 and keeps your data and settings.

- **kolahal-0.4.1.apk**: the full build.
- **kolahal-0.4.1-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no notifications in the log, no media controls and no calls in the log. Play Protect blocks sideloaded apps that have an accessibility service or notification access (in India and some other countries); this one has neither, so take it if the full build won't install. Both APKs use the same package and key, so either installs over the other.

## What's new

- **How much log to keep**: `config set log.keep-lines <number>`, from 500 to 50,000 lines (5,000 unless you change it). Typed commands are counted apart, so a lot of output can't push your ↑ history out.

## Fixed

- A script could fill the log past its limits: `console.error` lines and refused `launcher.run` calls weren't counted. A run now logs at most 500 lines and 256K characters, error lines and each line's link and other details included.
- `launcher.run` sends at most 10 commands per run, and a script started by another script's `launcher.run` can't send any, so scripts can't start each other without end.

**kolahal-0.4.1-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
