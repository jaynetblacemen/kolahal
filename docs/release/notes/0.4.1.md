Kolahal 0.4.1, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.0 and keeps your data and settings.

- **kolahal-0.4.1.apk**: the full build.
- **kolahal-0.4.1-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no notifications in the log, no media controls and no calls in the log. Play Protect blocks sideloaded apps that have an accessibility service or notification access (in India and some other countries); this one has neither, so take it if the full build won't install. Both APKs use the same package and key, so either installs over the other.

## What's new

- **Script lines have a title and a body**: `log(title, body)` shows the title in bold with the body muted under it, and every line a script logs is now a title. `logs(list)` logs one title line per item.
- **Every theme in a dark and a light version**: the phone's dark mode picks one and Kolahal switches with it. **Always dark** (Settings → Look & feel, or `config set theme.always-dark on`) keeps the dark one. The theme builder's **Dark** and **Light** switch which version you change; themes you made earlier look the same in both until you change their light one.
- **How much log to keep**: `config set log.keep-lines <number>`, from 500 to 50,000 lines (5,000 unless you change it). Typed commands are counted apart, so a lot of output can't push your ↑ history out.
- **Formatted text in script lines**: `md.log` reads Markdown (bold, italic, strikethrough, `++underline++`, code, and lists in the body), and `fmt.bold`, `fmt.italic`, `fmt.underline`, `fmt.strike`, `fmt.code`, `fmt.color` and `fmt.list` style parts of any line, for text from the web that Markdown would misread. `log` itself stays plain. Colours go by the theme's roles (`good`, `warn`, `bad`, `accent`, `link`, `info`, `muted`, `text`), so they read in every theme; themes gain **Good** and **Warning** colours for them, which the theme builder can change.
- **The library's scripts use titles, styles and colours**: what failed shows as a red title with the reason under it, hints are muted, and values stand out in bold. `countdown` colours past dates, this week's and today's. `releases` starts out watching Kolahal too, and `releases list` shows each repo as a line of its own; tap one for its releases.
- **The app selector vibrates as you move**: a tick for each letter along the edge, a lighter tick for each app in the list, and a short buzz when you move between the two.

## Removed

- **The `todo` library script**: the built-in `todo` always ran instead of it, and a backup restore dropped it. A copy you installed stays, under Scripts.

## Fixed

- A script could fill the log past its limits: `console.error` lines and refused `launcher.run` calls weren't counted. A run now logs at most 500 lines and 256K characters, error lines and each line's link and other details included.
- `launcher.run` sends at most 10 commands per run, and a script started by another script's `launcher.run` can't send any, so scripts can't start each other without end. `rss` and `crashes` must be typed.
- **Settings and other pages**: the keyboard no longer covers the field you are typing in; filters, search and scroll stay while the editor is open; setting a value back to its default makes it unchanged again; the same message twice shows twice.
- **Go to line** in the editor is readable on light themes.
- **Screen readers** name the header's ⚙ and network items and the jump-to-newest button.
- **Todos, notes and reminders**: after `rm`, the numbers in the suggestions are right at once, so the next one picked is the one you mean.
- **Typing**: an apostrophe inside a word stays (`sms mom I'm late`, `rename x = Bob's`); `sms` from a contact suggestion takes the whole number; "did you mean" fills the prompt instead of running.
- **The log**: older lines load while the private space is locked; a fresh screen never brings back lines `fresh` hid; "Delete command and output" no longer takes a later call or install line with it.
- **Feeds**: a read item no longer comes back as new once a feed holds 300; `feed fetch` for all feeds reports errors; `feeds every` and resetting `feeds.wifi` take effect at once.
- **Notifications**: `notifs unmute` works from the `notifs muted` list; a notification dismissed and posted again with the same text (a daily reminder) is logged again.
- **Apps**: an app you disable is no longer logged as uninstalled, nor as installed when you enable it again.
- **Backups**: a restore keeps your scripts whose name an app also has; it no longer brings another phone's record of calls and apps (which logged every app as installed); an export too big to import back says so. A folder export only deletes files of scripts you deleted on this phone.
- **Widgets** restored by Android onto a new phone wait to be added again instead of being removed.
- **Scripts**: daily times stay on time across daylight-saving changes and late runs, and setting them in a script's sheet switches it on; run headers follow `clock.24h`; `json.decode` raises an error for text that isn't JSON; `http.cached` makes room among its own entries when the store is full, and takes `nil` as the default lifetime; `rss.fresh` handles empty ids; an empty `@desc` stays empty.

**kolahal-0.4.1-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
