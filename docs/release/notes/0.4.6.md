Kolahal 0.4.6, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.5 and keeps your data and settings.

- **kolahal-0.4.6.apk**: the full build.
- **kolahal-0.4.6-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no notifications in the log, no media controls and no calls in the log. Play Protect blocks sideloaded apps that have an accessibility service or notification access (in India and some other countries); this one has neither, so take it if the full build won't install. Both APKs use the same package and key, so either installs over the other.

## What's new

- **Pick a script's daily time on a clock**: the clock in a script's **Daily at** box opens a time picker; the time you pick is added and set at once.
- **Find the library scripts that differ from Kolahal's, and see how**: the Scripts tab's **Differs from the library** chip shows the ones you edited, and any left from an older Kolahal. **Compare**, in a card's details or a script's sheet, shows its lines against the library version: those only in the library version in red, those only in yours in the theme's colour.
- **Kolahal's Discord server**: Settings → About → **Discord**, for questions, ideas and help from other people using Kolahal. Bugs and feature requests go on GitHub, each with its own form, and a security problem privately, as the website's new Security page says.

## Changed

- **The app selector is easier to reach and smoother to slide**: left open, its list widens almost to the edge, so your thumb reaches every row, the top ones too, from its own side; and sliding along the letters, the list glides to each letter's apps instead of jumping there.
- **The Scripts tab shows on and off by colour**: an on script's card is tinted in the theme's colour and an off one's fades; in a card's details, what a script may do is filled when on and faded when off, without ✓ and ✕. **Reset to the library's** is now **Reset to library version**, a smaller outlined button beside **Compare**, its icon in the error colour, and an older copy you didn't edit offers **Update from library**, as its sheet does.
- **Scripts never hold a secret's value.** `secrets.get` now returns a stand-in, and Kolahal puts the value in its place only in a request to a site the `@secret` line names, over https. A script that changes or hides the stand-in sends nothing. A script that needs to work on the key itself (encode it, sign with it) no longer can. The clipboard and a script's store refuse a secret, and a request can't set its own `Host` header. New code without a key's `@secret` line forgets its value.
- **Code you didn't write that starts going online starts with the internet off**: an update or a file whose code now makes requests asks first, like a new `@uses`. A script that runs commands (`launcher.run`) has an Internet switch too, and without it `search`, `yt`, `wiki`, `maps` and `play` with words are refused: they hand the words to a site.
- **A script's runs end on time**, in JavaScript as in Lua: a run stuck in a loop the engine can't interrupt is stopped after its minute, and `sleep` and requests wait no longer than the run has left.
- **What one run may write is bounded**: at most 10 notifications and 20 header-line changes, a clipboard text of 100,000 characters, store keys of 512 characters, and a store's 16 MB counted in bytes, keys included. A line a script logs keeps only `url`, `image`, `copy` and `mono`.
- **A script's event runs wait their turn**: one script's runs on events go one after another, never side by side, and an event queued before its switch went off doesn't run it.
- **The phone's own networks count as local**: a script without `@uses lan` can't reach your router or other devices on an IPv6 or public-address network.
- **`device.setWork`** takes `true` / `false` or `"on"` / `"off"`, alike in Lua and JavaScript.

## Fixed

- **One script's long error message could freeze home**: the script list became unreadable, home's log stopped updating and no trigger fired. The message kept with the script is cut short now, and one left from before is repaired.
- **A JavaScript value nested very deep crashed the script process**, and every script running with it.
- **An emoji-heavy notification** could fail to start `@on notification` scripts, and keep it from the scripts after them.
- **The private space's notifications** no longer reach scripts, as its apps don't.
- **Two apps with the same name in one profile** complete apart for `uninstall`, `hide` and the like, each by its package; a package name finds its app.
- **Adding a widget** survives Android stopping Kolahal while the widget's own setup screen is open.
- **The widgets page** runs right to left in right-to-left languages.
- **The app selector** isn't rebuilt each time the keyboard closes.
- **Wallpaper showing** takes effect at once: turned on while home was open, the wallpaper didn't show (and old lines could smear) until Kolahal restarted.
- With the wallpaper showing, a log line you swipe stays see-through instead of a solid band, and the charging bolt in the battery icon is cut out rather than painted in the page's colour.

**kolahal-0.4.6-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
