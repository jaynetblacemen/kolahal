Kolahal 0.3.0, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.2.5 and keeps your data and settings.

- **kolahal-0.3.0.apk**: the full build.
- **kolahal-0.3.0-lite.apk**: the same app without the accessibility service and notification access. Play Protect blocks sideloaded apps that have either (in India and some other countries), so use this one if the full build won't install. It has no screen lock (`lock`, double-tap), no `notifs`, no media controls, and scripts can't read your notifications. Both use the same package, so either installs over the other.

To install the full build where Play Protect blocks it: Play Store → profile → Play Protect → ⚙ → turn off "Scan apps with Play Protect", install, then turn it back on.

## What's new

- **See home while you change how it looks.** Drag a slider for text size, line height, log spacing, key bar or prompt height, suggestions, chip height, or the app selector or widget height: Settings fades away except that slider, and home shows underneath at the value under your finger, like the brightness slider in the quick settings. Let go to save it. The typing ones show home as if you were typing. You can also hold the eye at the top of Look & feel, Home screen, Log and Typing to see home; a quick tap on it tells you to hold.
- **Shorter settings rows.** A changed setting shows a small reset icon (↺) right after its name, instead of a Reset button and "· changed".
- **Whole descriptions in the suggestion list**, if you want them: Settings → Typing → Suggestions → Wrap descriptions (`suggestions.wrap`). A command's or setting's description then wraps over more lines instead of being cut short. Off by default.
- **Up to 30 suggestions again** by default (0.2.3 to 0.2.5 showed 5). If you changed it yourself, your number stays.
- **Clearer setting names**, ready for themes of your own later. Your settings move over by themselves on first start, the old names still work in `config` (it tells you the new name), and older backups import as before. The `theme` and `font` commands are unchanged. The renames:
  - `theme` → `theme.name`, `gui.colors` → `theme.settings-colors`, `font` → `font.family`, `statusbar` → `screen.bars`
  - `suggestions` → `suggestions.max`, `keybar` / `keybar2` → `keybar.row1` / `keybar.row2`, `keyboard.onhome` → `keyboard.on-home`, `launch.instant.min` → `launch.instant-letters`
  - `log.lineheight` / `log.keepdays` → `log.line-height` / `log.keep-days`
  - `feeds.log.lines` / `feeds.backlog.read` / `feeds.read.shown` → `feeds.log-lines` / `feeds.backlog-read` / `feeds.read-shown`
  - `gesture.doubletap` / `gesture.swipedown` / `gesture.swipeup` → `gesture.double-tap` / `gesture.swipe-down` / `gesture.swipe-up`
  - `gesture.swipeup.on` is gone: `gesture.swipe-up` set to `none` (the default) turns swiping up off, and any other action turns it on. If you had it on, it stays on.

## Fixed

- A crash in Settings while scrolling Look & feel, seen on a Samsung phone ("LayoutNode … not found in RectList"): the theme and font previews no longer use a list that loads ahead of time.

**kolahal-0.3.0-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.

Both APKs are built from `3c824d4`, the commit this tag points to, and signed with the debug key like 0.2.5 (there is no release keystore yet).
