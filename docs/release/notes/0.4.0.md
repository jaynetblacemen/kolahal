Kolahal 0.4.0, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.3.1 and keeps your data and settings.

- **kolahal-0.4.0.apk**: the full build.
- **kolahal-0.4.0-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no notifications in the log, no media controls and no calls in the log. Play Protect blocks sideloaded apps that have an accessibility service or notification access (in India and some other countries); this one has neither, so take it if the full build won't install. Both APKs use the same package and key, so either installs over the other.

> **Scripts that call `launcher.run`** now need a `@uses commands` line at the top (`-- @uses commands` in Lua, `// @uses commands` in JavaScript). Without it, the script stops and says what to add.

## What's new

- **Access switches for every script**: Scripts → tap a script → Access. Switch off its internet, its header line, its notifications, anything it declares with `@uses`, or any event it runs on. Switched off, a script gets nothing where nothing is an honest answer (no apps, no notifications, no clipboard, no header line) and stops where it isn't (internet, your local network), with a line to tap to allow it again.
- **Hide a script from the header**: long-press its line there.
- **Turning on a script asks first** about what it declares with `@uses`, everything on, so you can switch off what you don't want.
- **In the terminal**: `script access <name>`, `script allow <name> <what…>` and `script deny <name> <what…>`.
- **For scripts**: `allowed(what)` tells a script what it may use, and `@uses commands` covers `launcher.run`.
- **Search the log**: type `/` and some words at the prompt. The log shows only the lines that have them, from everything it keeps, with the words marked; tap one to see it in the log. Commands, where a line came from (`/weather`) and its link (`/github.com`) count too.
- **API keys stay out of scripts**: a script names a key with `@secret NAME site description` and reads it with `secrets.get("NAME")`. Set the value in the script's sheet or with `script secret <name> <NAME>`. Values are encrypted on the phone, never in backups or the log (they show as `••••`), and are sent only to the site the line names.
- **Settings, Feeds and Scripts are tabs** of one screen: feed settings moved from Settings into the Feeds tab, and the Scripts tab shows a card per script, compact or with its details (header line, next run, usage, events, access), with filter chips and search. **Add script** holds new, library, shared and imported scripts.
- **The editor's reference** (**[?]**) lists every `@` line too, and inserts it as a comment line.
- **Widgets side by side**: each widget has a width as well as a height (in twelfths of the page), so square widgets can share a row. Height changes 8dp at a time, holding − or + keeps going, and **Square** makes a widget as tall as it is wide.
- **Rename a script**: the ✎ beside its name in its sheet, or `script mv <name> <new-name>`. Its timers, access, data, keys and header line stay with it.
- **Get more scripts**: Scripts → Add script → Get more scripts, or `script get`. Scripts shared by people who use Kolahal, in [kolahal-scripts](https://github.com/mtwabpin/kolahal-scripts) on GitHub, each checked and read before it is added. See what a script does, what it uses and its code before you install it; updates show up in Scripts.
- **Scripts describe themselves**: `@title`, `@author`, `@version`, `@tags`, the timer they suggest (`@every 1h`, `@at 07:00`), `@notify`, and `@requires` for the oldest Kolahal they work with. The Scripts screen shows them, scripts added from a file or a folder get their suggested timer, and the library scripts carry them too.

## Removed

- **The `feeds` script left the library**: the built-in feed reader (`feed add <url>`, or the Feeds screen) does the same and more. It lives on as `rss-digest` in [kolahal-scripts](https://github.com/mtwabpin/kolahal-scripts), and a copy you installed stays.

## Fixed

- A switched-off script's line stayed in the header.
- Long-press menus: the last actions of a long menu couldn't be reached; the actions now use the phone's font, and a line's link shows under its title.
- The empty widgets page no longer says to move widgets from home.
- The message after importing a backup starts with a capital letter and says "1 script", not "1 scripts".

**kolahal-0.4.0-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
