Kolahal 0.4.9, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.8 and keeps your data and settings.

- **kolahal-0.4.9.apk**: the full build.
- **kolahal-0.4.9-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap) and no calls in the log, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## What's new

- **See how far along a track is**: a thin bar under what's playing in the header fills as the track plays, and follows you when you seek or start another track. A stream with no length leaves it empty.
- **Share a crash report from Settings**: Settings → About → Crash reports → a report now has **Share** beside **Email the developer**, for a chat or a GitHub issue.
- **`wallpaper match`**: with gesture navigation, going home passes through your phone's own launcher, which shows the wallpaper for an instant. This sets the home screen's wallpaper to the theme's colour, so nothing stands out, and changes it when the theme or dark mode does. Set another wallpaper and Kolahal leaves it alone from then on. It asks first, as the old wallpaper can't be brought back; the lock screen keeps its own. Three-button navigation doesn't have the flash.
- **The source code, one tap away**: the `source` command and Settings → About → **Source code** open Kolahal on GitHub.

## Fixed

- **Reminders from a backup**: a repeat Kolahal couldn't read, from a damaged file or a newer version, crashed the app each time it was due. The reminder now fires once and says it won't repeat.
- **Failed automatic backups**: one that failed left an empty file, and enough of those pushed your real backups out of the folder. A failed one leaves nothing now, and empty files don't count.
- **A key a website sends back**: if a site repeated a script's secret in its answer, `http.cached` and `rss.fresh` kept it in the script's store, and so in backups. A response holding a secret isn't cached now, and a feed item's id has it masked.
- **What stays out of a backup file**: the lines printed by `calls`, other lines with someone's number (`contacts`, `Dialing`), and lines from a private space went into backup files, against what Settings and the guide say. They stay on the phone now.
- **Scripts sharing a daily time**: when two or more scripts had the same `@at` time, the first to finish could cancel the next one's start, and Android then stopped the scripts' process, which could leave a script not run that morning. They now all run.

**kolahal-0.4.9-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
