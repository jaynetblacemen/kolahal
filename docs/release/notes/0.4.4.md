Kolahal 0.4.4, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.3 and keeps your data and settings.

- **kolahal-0.4.4.apk**: the full build.
- **kolahal-0.4.4-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no notifications in the log, no media controls and no calls in the log. Play Protect blocks sideloaded apps that have an accessibility service or notification access (in India and some other countries); this one has neither, so take it if the full build won't install. Both APKs use the same package and key, so either installs over the other.

## What's new

- **The app selector goes a letter at a time**: slide along the edge to a letter, and it shows big in a circle beside your thumb, the letters around it bulging out from the edge so you see which way to go, with a tick for each; home dims and the list narrows while your thumb is down, so they stay clear of it. Every letter gets the same stretch of the edge. The list holds still with that letter's apps level with the circle and the others faded back; slide off the edge onto it to pick one, as before. **Only the letter's apps** (`selector.filter`) lists just those. **Slide through** (`selector.browse`) set to `apps` brings back the glide through the whole list, an app at a time, now with the circle too.
- **Night Do Not Disturb and Night work profile** in the script library (`script install night-dnd`, `night-work`): Do Not Disturb on, or the work profile paused, at 11 PM, and back at 7 AM. If it was on (or paused) already at 11 PM, you did it, and the script leaves it alone at both times: it only undoes what it did.
- **Scripts can see and set Do Not Disturb and the work profile**: `device.dnd()` and `device.setDnd(mode)` with `@uses dnd`, `device.work()` and `device.setWork(on)` with `@uses work`, each off until you allow it.

## Changed

- **Scripts' daily times are on time**: each one is an alarm now. With Alarms & reminders allowed for Kolahal (`remind exact` asks for it), a script runs on the minute even while the phone sleeps, in the foreground for its few seconds (which Android needs before Kolahal may pause the work profile); otherwise within the hour. Before, a daily run waited for a network, and at night often for an hour or more. A run at a daily time is told which time it was (`event.time`), and waits for a network only if the script makes requests and there is none.

**kolahal-0.4.4-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
