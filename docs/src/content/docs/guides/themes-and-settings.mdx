## Fonts

```sh
font                 # list the fonts; tap one to use it
font jetbrains-mono
font import          # pick your own .ttf / .otf
```

The terminal font is used everywhere the terminal draws text: the log, prompt, header,
suggestions, key bar and the script editor. Choices:

| Name | Font |
| --- | --- |
| `system` | the phone's monospace font (default) |
| `jetbrains-mono` | [JetBrains Mono](https://www.jetbrains.com/lp/mono/) |
| `fira-code` | [Fira Code](https://github.com/tonsky/FiraCode), with programming ligatures (`=>`, `!=`, …) |
| `ibm-plex-mono` | [IBM Plex Mono](https://github.com/IBM/plex) |
| `source-code-pro` | [Source Code Pro](https://github.com/adobe-fonts/source-code-pro) |
| `custom` | a font file you imported |

The bundled fonts ship in Regular and Bold under the SIL Open Font License 1.1 (licence texts are
in the app's `assets/licenses/`). `font import`, or the import card in the settings screen's font
previews, copies a `.ttf` or `.otf` (up to 10 MB) into the app and switches to `custom`; importing
again replaces it. If the custom font goes missing or can't be read (for example after restoring a
backup on another phone), the terminal falls back to the system monospace and says so once in the
log. Text size stays a separate setting: `config set font.size 16`, or pinch the log.

## Settings screen

`settings` (or `config` with no arguments, or ⚙ in the header) opens a Material 3 screen with
grouped lists: switches, connected button groups, sliders and theme preview cards. It has:

- **Backup**: export and import a [backup file](../backup/).
- **Scripts**: the script manager and the setup checklist.
- **Appearance**: theme, settings colours, text size.
- **Header**: which items the header shows.
- **Log**: times, dimming, spacing, how long to keep the log.
- **Launching**: Enter behaviour, suggestions, search engine.
- **Gestures**: the three [gestures](../gestures/).
- **Keyboard & key bar**: the key bar rows and soft keyboard behaviour.

Changed settings get a **Reset** button.

## The config command

Everything on the settings screen is a config key, also settable from the prompt (the full list is
in the [configuration reference](../../reference/config/)):

```sh
config ls                    # every key with its value; * marks changed ones; tap a line to edit it
config get font.size
config set font.size 16      # 'set font.size 16' and 'config font.size 16' work too
config reset font.size
config reset all
```

Booleans take `on`/`off` (also `true`/`false`, `yes`/`no`, `1`/`0`). Numbers have a range and
choices a fixed list; an invalid value prints what is allowed. While you type `config set`,
suggestions offer keys and then valid values.
