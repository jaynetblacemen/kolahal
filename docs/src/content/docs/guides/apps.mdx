## Launching

Type part of an app name and press Enter. The [basics](/getting-started/basics/#the-prompt)
page explains exactly which app Enter picks. `open <app>` (alias `launch`) does the same
explicitly and takes profile flags:

```sh
open maps
open gmail -w
```

## Listing

```sh
apps                 # grid of chips (alias: ls)
apps -l              # one per line
apps work            # one profile: work, personal, private
apps hidden          # only hidden apps
apps -a              # include hidden apps
```

Tap a chip to launch it; long-press for launch, shortcuts, the other-profile copy, app info, copy
package name, hide and uninstall.

## Favourites

<span class="k-new">new</span> Pinned apps lead the suggestion strip whenever the prompt is empty, in the order you
pinned them, followed by your most-used apps.

```sh
pin maps                     # or long-press an app → Pin to favourites
pins                         # grid of pinned apps
unpin maps
```

Pins are part of the [backup file](/guides/backup/).

## Hide and rename

```sh
hide calculator              # gone from lists, search and suggestions
apps hidden                  # see what's hidden
unhide calculator
rename youtube = yt          # custom label
rename yt =                  # empty restores the original label
rename chrome -w = work web  # flags pick the profile
```

Hidden apps and custom labels are part of the [backup file](/guides/backup/).

## App shortcuts

Launcher shortcuts (the menu you get by long-pressing an icon in other launchers) work too. They
need Kolahal as the default launcher.

```sh
shortcuts maps               # list them; tap one to start it
open maps:home               # start the shortcut whose label best matches "home"
```

They also appear in every app's long-press sheet.

## Aliases

```sh
alias m = open maps          # define
alias                        # list
alias m                      # show one
unalias m                    # remove
```

Aliases expand the first word (up to five levels, without cycles). A built-in command name can't
be an alias.

## App info and uninstall

```sh
info whatsapp
uninstall some-game -w
```

### Install, update and uninstall log

Installs, updates and uninstalls show up in the log: the app name, then its package name and its version
on dimmed lines below, with a profile tag and `+` / `↻` / `−` at the end of the first line
(`Updated Maps [W] ↻`). An update is always one line, and so is an uninstall followed by
a reinstall within 20 seconds. Because of that window, an uninstall line appears about 20 seconds
after the app is gone, or as soon as you come back to the home screen after that. Changes made while
the launcher wasn't running are caught up when it starts. `installs [<n>]` lists the recent history
with dates.

## Screen time and unlocks

```sh
usage            # time per app today (alias: screentime)
usage 7          # last 7 days (1–30)
unlocks          # today's unlock count
unlocks 7        # bar chart for the last week (1–30)
```

`usage` needs **Usage Access** (`usage-access`). Unlock counts use Usage Access when granted and
fall back to counting `ACTION_USER_PRESENT` broadcasts while the launcher is running.
