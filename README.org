#+TITLE: Kolahal
#+SUBTITLE: A keyboard-first terminal launcher for Android

Kolahal (=com.mtwabpin.kolahal=) is a terminal-style home screen for Android 9 and newer. Type a few
letters and press Enter to open an app or run a command; every command and its answer stays in a
log. It reads RSS and Atom feeds, keeps todos, notes and reminders, controls media and the device,
runs your own scripts in *Lua 5.4* or *JavaScript (QuickJS)*, and works with the work profile and
private space.

#+begin_quote
Kolahal is developed with AI assistance. The developers review every change except the tests.
#+end_quote

* Get it

- *APK*: the [[https://github.com/mtwabpin/kolahal/releases/latest][latest release]] on GitHub has the full build, with everything in it, and the
  Play build for phones where Play Protect blocks the full one. The [[https://mtwabpin.github.io/kolahal/getting-started/install/][install guide]] says how
  to sideload them.
- *Google Play*: coming. The Play version leaves out the screen lock, notification access
  (notifications in the log, media controls and the now-playing line) and calls in the log, which
  Play's policy rules out.

* Tests

JVM unit tests (=app/src/test=) cover pure logic: parsing, ranking, layout maths and formats.
On-device tests (=app/src/androidTest=) cover the script engines and sandbox, commands, storage and
backup, and the home and settings screens. The on-device ones install the debug build (package
suffix =.debug=) and change its settings; run them on an emulator.

*Coverage: 44.6%* of the app's code lines (0.4.0), counting a line when either kind of test runs it.
It is measured at each release with JaCoCo, on an Android 16 emulator:

#+begin_src sh
./gradlew -Pcoverage :app:createDebugUnitTestCoverageReport :app:createDebugAndroidTestCoverageReport
perl tools/coverage.pl   # the total, and each package
#+end_src
